The Reading-Teal Rule

會被讀的青字一律用 teal-700

主色 #05556C 在白、slate-50、teal-50 上有 7.3–8.3:1。teal-600 是它的亮階，只給圓點、邊框與 focus 外框，不拿來寫字、也不當按鈕底。

The Signal-Not-Surface Rule

深青不鋪超過一個標籤大小的面

全頁最大的青色面積，就是滑過中的主要按鈕。區段底色只在白與 slate-50 之間切換。

Do's and Don'ts

守住灰階，青色只留給讀數

Do

  • 區段固定順序：青色英文眉標 → 粗體中文標題 → 灰色說明 → 卡片網格。
  • 區段底色交替：白與 slate-50，區段底部一條 slate-200 細線。
  • 青字一律 teal-700：teal-600 只用在圓點與邊框。
    teal-700 · 8.33:1
  • 卡片：白底、1px slate-200 邊框、16px 圓角、無陰影。
  • 主要按鈕：slate-900，hover 才轉青；每組 CTA 一主一次。
  • 清單符號：6px 青色圓點，不用勾勾圖示或編號圓圈。

Don't

  • slate-400 寫需要被讀的字：白底只有 2.56:1；英文標題、副標一律用 slate-500。
    原檔 System Architecture · 2.56:1
  • 混用兩種青色當字色或按鈕底：teal-600 只給圓點、邊框、focus 外框；文字與按鈕 hover 底一律 teal-700。
  • 只靠 1px 邊框變色表示 focus：或拿掉 outline 卻不補替代樣式。按鈕用 2px teal-600 外框，輸入框用 2px 青邊加光暈。
  • 點陣網格鋪到其他區段：它只屬於系統架構面板。
  • 漸層、插圖、照片底圖：這套系統的視覺全部由文字、細線與圓點構成。
