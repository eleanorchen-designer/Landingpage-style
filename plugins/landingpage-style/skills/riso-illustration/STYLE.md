# Riso Grain Illustration — 風格規格

一句話：**扁平色塊 + 孔版印刷網點 + 乾刷疊色 + 蠟筆毛邊**。物件像用兩三版油墨印在紙上：色塊沒有外框，陰影只靠網點密度，顏色半透明地疊在一起，邊緣微微破碎。

所有數值都以 **790×870 畫布** 為基準（原型尺寸）。畫布大小不同時，形狀依比例縮放，但**網點螺距與線寬不縮放**（它們代表印刷網屏，是固定的物理尺寸）。

## 2. 顆粒感 Texture / Grain

三種顆粒，各有不同來源，不要混為一談：

1. **網點屏（halftone screen）**——最主要的顆粒。45° 斜排的圓點網格，**螺距 5px**（細 4px、粗 8px）。網點顏色＝該物件的深色（深青物件用 `teal-ink`，灰物件用 `graphite-ink`，藍物件用 `sky-shade`）。
   - 主物件整面鋪一層淡網點（色調 ≈ 0.3），所以近看深青色面全是小點。
   - 網點**最密的地方**：形狀的下緣與右緣（光從左上來）、兩物件交疊處、灰白物件的暗面。下緣最後 10px 幾乎變成棋盤格（色調 ≈ 0.9）。
2. **細雜訊（speckle）**——極稀疏的深色小點與紙色小點，讓色面不死平。肉眼在 100% 下幾乎看不出，只有放大才見。
3. **紙紋斑駁（mottle）**——大尺度、±3% 明度的雲狀起伏；灰白物件額外有「揉皺紙」的低對比明暗。

濾鏡：`riso-ht` / `riso-ht-fine` / `riso-ht-coarse` / `riso-edge-ht`（1）、`riso-grain`（2、3）、`riso-crumple`（灰白物件的 3）。

## 3. 筆刷與邊緣 Brush & Edge

- **乾刷（dry brush）**：主物件內有寬而鬆的藍色斜刷痕，方向由左下往右上，**約 −35°**。刷痕兩端柔和漸淡、寬窄不一，不是條紋圖案。偶爾有 1–2px 的淡色「刷毛脊線」（數量少，整張圖 5–8 條）。
- **無外框**：色塊靠色差分界，不描邊。唯一的線是灰白物件上的細輪廓與文字線。
- **蠟筆毛邊**：所有實心形狀邊緣輕微抖動（位移 ≈ 4px）並破碎成細碎鋸齒；不是模糊，也不是規則波浪。
- **套印錯位**：主物件外緣有一道 3–5px 的淡色（`tint-pale`）殘影，向左上偏移，像兩版油墨沒對準。
- **紙張透出**：筆觸沒有完全蓋住，色面內有零星紙色小點。

濾鏡：`riso-drybrush`、`riso-ridges`、`riso-rough`、`riso-line`；錯位殘影是手動畫一個偏移的淡色副本。

## 4. 陰影 Shading

- **完全沒有柔和投影**（no drop shadow、no blur shadow、no 漸層暈影）。
- 明暗只有兩種手段：
  1. **網點密度**：同色網點由稀到密表示由亮到暗。用 `stop-opacity` 0 → 0.7–0.9 的漸層當色調，交給 halftone 濾鏡轉成網點。
  2. **深色色塊**：兩面交接處（例：手掌與手指之間）放一塊較深的網點楔形或實心深色塊。
- **光源固定在左上**。暗面一律在右側、下側。
- 細輪廓線的**一側**貼著一條由深到淺的網點楔形，表示摺面；另一側乾淨。
- 物件之間不畫投影；前後關係靠疊放順序與交疊處的網點加深表現。

## 5. 疊色與混合 Layering & Blend

- 每個物件由下而上：**底色 → 加深漸層 → 淡網點屏 → 乾刷水洗 → 刷毛脊線 → 邊緣網點 → 實心深色元素 → 線**。
- 水洗層用一般混合（normal）＋不透明度 0.55–0.65：天藍 `#17BAE8` 疊在深青 `#05556C` 上，形成較亮的青色刷痕。不要用 multiply，會變髒。
- 淺色疊層（tint 捲角、高光帶）用 `fill-opacity` 0.8–0.85，下層顏色要透出一點。
- 實心深色元素（淺色（mark）方塊、閃電）**不透明**，壓在水洗之上，形成最強的明度對比。
- 色調一律用 `fill-opacity` / `stop-opacity` 控制，**不可用 `opacity` 屬性**（opacity 在濾鏡之後才套，網點會整片變淡而不是變稀）。

## 6. 線條 Line Work

| 線 | 顏色 | 粗細（790 寬畫布） | 端點 | 說明 |
|---|---|---|---|---|
| 文字線 / 刻度線 | `mark` | 5–5.5px | round | 3–4 條，長短不一，左對齊 |
| 輪廓線 | `graphite` | 2.4–2.8px | round | 只畫在灰白物件內部的摺線，每物件 2–4 條，短而微彎，不封閉 |
| 點綴線 | `amber` | 3–3.4px | round | 整張圖唯一一條。自由塗鴉，有 1–2 個小迴圈，從互動點（筆尖、插腳）出發，延伸並**穿出主物件上緣**，結尾帶一個小勾 |
| 高光細線 | `sky-light` / `tint-pale` | 3px | round | 沿圓柱或捲角的亮側，只畫一段 |

所有線都套 `riso-line`（輕微抖動＋墨色破口）。

## 7. 構圖 Composition

- **畫布**：直式 790×870（≈ 10:11）；可改 1:1 或 4:3，但物件比例照下列規則。
- **主物件**（深青）：寬約畫布 **55–62%**、高約 **72–76%**，偏左放，左邊界留 4–12%。
- **第二物件**（暖灰白）：從右側或右下進入，與主物件**交疊 20–35%**，尺寸約主物件的 50–70%。
- **天藍物件**：細長，斜向（−55° 至 −60°，左上往右下），跨過兩物件交界。
- **點綴線**：從互動點出發往上，越過主物件上緣 20–40px。
- 整體內容框佔畫布約 **85% 寬、83% 高**；上方留白多於下方。物件可以碰到畫布底緣或右緣（線材可出血），但主物件不出血。
- 背景永遠是平塗 `paper`，**不加任何紋理、漸層或地面陰影**。
- 一張圖 2–3 個物件就好；資訊不靠文字，不放可讀字。

## 8. Do / Don't

| ✅ Do | ❌ Don't |
|---|---|
| 陰影用網點密度表現 | 用 drop-shadow、blur、柔和漸層暈影 |
| 色塊無外框，邊緣微毛 | 每個形狀都描黑邊，或邊緣銳利乾淨如向量 icon |
| 天藍乾刷斜向、寬鬆、兩端漸淡 | 規則條紋、橫平豎直的刷痕 |
| 琥珀黃只用一條線 | 琥珀黃出現在面、或出現兩條以上 |
| 網點螺距全圖一致（5px 為主） | 網點忽大忽小、或隨物件縮放 |
| 光源固定左上，暗面在右下 | 每個物件光源方向不同 |
| 背景平塗 `#F3F5F9` | 背景加紙紋、漸層、色塊或場景 |
| 2–3 個簡化物件，大剪影 | 細節繁多、寫實比例、可讀文字 |
| 色調用 fill-opacity / stop-opacity | 用 opacity 屬性控制網點色調 |
| 灰白物件加 `riso-crumple` 揉紙感 | 灰白物件留純平灰 |
